# FACE VALUE

Игра на знание реальных цен для Telegram Mini Apps. Игрок видит фото товара, вводит свою оценку цены в долларах и получает до 1000 очков за ответ. В раунде 5 вопросов, максимум 5000 очков.

Это викторина: никаких ставок, денежных призов и платных случайных предметов.

## Что внутри

- **Главное меню:** «Играть», «Рейтинг», «Моя статистика», «Как играть» и личный рекорд.
- **Раунд из 5 товаров.** Внутри раунда товары из разных категорий и разных ценовых уровней. Товары соседних раундов не повторяются.
- **После ответа** видно реальную цену, твой ответ, разницу, очки, пояснение, источник цены и дату проверки.
- **Итоги раунда:** очки, количество удачных ответов, точность, рекорд, кнопки «Играть ещё» и «В меню».
- **Личная статистика** хранится на этом устройстве (localStorage) и не ломается, если данные повреждены.
- **Рейтинг.** Пока сервер не подключён, экран честно пишет «появится после подключения сервера». Сервер уже написан (папка `server/`), но не запущен в интернете.
- **База:** 100 товаров в 8 категориях. Ещё 16 товаров с проверенной ценой ждут фото (список `PENDING`).

## Запуск на ноутбуке

### Способ 1: без установки

Распакуйте архив и дважды кликните по `index.html`. Игра откроется в браузере.

### Способ 2: через локальный сервер

Нужен Python (на Mac обычно уже есть).

1. Откройте Терминал и перейдите в папку проекта: наберите `cd `, перетащите папку `face-value` в окно и нажмите Enter.
2. Выполните `python3 -m http.server 8000` (на Windows: `python -m http.server 8000`).
3. Откройте http://localhost:8000
4. Остановить сервер: `Ctrl + C`.

Чтобы посмотреть мобильную версию, в Chrome нажмите `F12` (Mac: `Cmd + Option + I`) и выберите значок телефона.

## Фото товаров

Для каждого товара в базе указана ссылка на официальное фото с той же страницы производителя, где проверена цена (`image.remote` в `js/data/questions.js`).

Сохранить фото локально, чтобы они не пропали из-за изменений на чужих сайтах, можно одной командой (нужен Node.js 18+, nodejs.org):

```
node tools/download-images.mjs
```

Скрипт скачает фото в `assets/products/`, проверит, что каждый файл — действительно картинка, и обновит `assets/products/manifest.js`. В конце он напечатает список фото, которые не скачались.

Как игра выбирает фото: сначала локальный файл, потом официальная ссылка. Если не открылось ни то ни другое, показывается аккуратная заглушка «Фото недоступно», и игра продолжается.

**Права на изображения.** Все фото принадлежат брендам. Для личного прототипа это обычная практика, но перед публичным, а тем более коммерческим запуском нужно убедиться, что использовать эти изображения разрешено. Варианты: пресс-материалы брендов с понятными условиями, собственные фото или партнёрские программы магазинов.

## Откуда цены

- Каждая цена — официальная цена в США (USD) на сайте бренда или его официального магазина.
- Все цены проверены **11.10.2026**.
- Товары со скидкой в базу не попадали. Для автомобилей и техники с вариантами указана базовая комплектация.
- Цены меняются. Перед публичным запуском проверьте их заново по ссылкам `source.url`.

## Как добавить товар

Скопируйте любой блок в `js/data/questions.js` и заполните поля:

```js
{
  "id": "my-product",              // уникальный id латиницей
  "category": "tech",              // tech | fashion | accessories | beauty | gaming | home | food | everyday
  "brand": "Apple",
  "model": "AirPods 4",
  "title": "Apple AirPods 4",
  "subtitle": "Базовая версия",
  "price": 129,                     // число, без $ и пробелов
  "currency": "USD",
  "region": "US",
  "note": "Пояснение, которое игрок увидит после ответа",
  "source": { "label": "apple.com", "url": "https://..." },
  "checkedAt": "2026-10-11",
  "status": "verified",
  "image": { "remote": "https://...фото...", "pageUrl": "https://...", "credit": "© Apple" }
}
```

После изменений запустите тесты: они проверяют, что у каждого товара есть цена, валюта, регион, источник, дата и фото, что товары не повторяются и что пояснения не раскрывают цены других вопросов.

## Тесты

Нужен Node.js 18+ (для тестов сервера — 22+). Из папки проекта:

```
node --test tests/*.test.js
cd server && node --test test/*.test.js
```

Ожидаемый результат: `# pass 26 / # fail 0` для игры и `# pass 17 / # fail 0` для сервера.

## Как считаются очки

Ошибка считается не в долларах, а во сколько раз ответ отличается от цены.

| Ошибка | Очки |
|---|---|
| до ±2% | 1000 |
| 10% | ≈ 900 |
| 25% | ≈ 760 |
| в 1,5 раза | ≈ 560 |
| в 2 раза | ≈ 240 |
| в 2,5 раза и больше | 0 |

Удачный ответ — 750 очков и больше. Точность ответа — `100% − ошибка в процентах`, но не меньше 0.

Формула находится в `js/scoring.js`. Сервер использует этот же файл, поэтому очки в игре и в рейтинге совпадают.

## Структура проекта

```
face-value/
├── index.html                всё приложение: меню, игра, итоги, статистика, рейтинг, правила
├── css/styles.css            дизайн, анимации, отступы под iPhone и Telegram
├── js/config.js              настройки (адрес сервера рейтинга; секретов нет)
├── js/data/questions.js      база: 100 товаров + PENDING (товары, которым нужно фото)
├── js/scoring.js             разбор ввода, очки, выбор вопросов (общий для игры и сервера)
├── js/stats.js               личная статистика в localStorage
├── js/engine.js              локальный и рейтинговый режим раунда
├── js/api.js                 запросы к серверу рейтинга
├── js/telegram.js            интеграция с Telegram WebApp
├── js/app.js                 интерфейс
├── assets/products/          локальные фото + manifest.js
├── tools/download-images.mjs скачивание и проверка фото
├── tools/build-public.mjs    публичная сборка для рейтинга (без цен в коде страницы)
├── tests/                    тесты игры
└── server/                   сервер рейтинга (Cloudflare Workers + D1), см. server/README.md
```

## Режимы работы

| Режим | Когда | Очки считает | Куда сохраняется |
|---|---|---|---|
| Локальный | браузер, или Telegram без сервера | телефон | только личная статистика |
| Рейтинговый | Telegram + указан `API_BASE` в `js/config.js` | сервер | личная статистика + общий рейтинг |

В локальном режиме цены лежат в коде страницы. Это нормально для обычной игры, но для честного рейтинга так нельзя. Поэтому для публикации с рейтингом есть сборка `node tools/build-public.mjs --api https://...`: она создаёт папку `dist/`, где цен в коде нет, а сервер сообщает цену только после ответа.
