# Crypto Academy

Интерактивный курс по криптотрейдингу с нуля: от устройства рынка до чтения графиков, анализа ситуаций, управления риском и собственного торгового плана. Самостоятельное приложение внутри репозитория: ванильный JavaScript, без сборки и без зависимостей.

> Образовательный проект. Не является инвестиционной рекомендацией. Все рыночные данные синтетические, реальные деньги и подключения к биржам не используются.

## Запуск

- Дважды кликните `academy/index.html` — курс откроется в браузере (работает и через `file://`).
- Или через локальный сервер: `cd academy && python3 -m http.server 8000` → http://localhost:8000

## Что внутри

| Раздел | Содержание |
|---|---|
| **Курс** | 7 модулей, 38 уроков + финальный экзамен (модуль 8). В каждом уроке: цель, теория, разбор графиков и примеров, типичные ошибки, практика, тест (5–8 вопросов), конспект, условия перехода. |
| **Практика в уроках** | 15 типов заданий: конструктор свечи, выбор свечи, определение тренда, разметка уровней кликом по графику, поиск точки на графике, постановка стопа, план сделки (вход/стоп/цель → «что было дальше»), чтение индикаторов, расчёты, ситуации, порядок шагов, классификация, торговый журнал, торговый план, бэктест. Графики в заданиях каждый раз новые. |
| **Paper Trading** | 10 000 виртуальных USDT, три вымышленных актива, рыночные и лимитные ордера, Stop Loss / Take Profit, комиссия 0,1% и проскальзывание 0,05%, история сделок, кривая капитала, статистика, максимальная просадка, режим обучения — разбор каждой сделки «тренером». |
| **Лаборатория стратегий** | Бэктест простых правил на синтетической истории с разделением на обучающий и проверочный отрезки. |
| **Калькуляторы** | Размер позиции и результат сделки, плечо и ликвидация, просадка и восстановление, математическое ожидание. |
| **Справочник** | Словарь (≈95 терминов, поиск), карточки с интервальным повторением, разбор ошибок (мои ошибки в тестах, в симуляторе, типичные ошибки), исторические кейсы (Mt. Gox, ICO, март 2020, Terra/LUNA, FTX, ETF 2024). |
| **Прогресс** | Процент прохождения, результаты тестов, XP и 8 уровней, 22 достижения, история обучения, ежедневные задания и серия дней, избранные уроки, «продолжить с последнего места», резервная копия прогресса. Всё хранится в `localStorage`. |

Уроки открываются последовательно: практика + тест ≥ 70%. Для повторения есть «свободный режим».

## Данные

Все графики генерируются алгоритмом (`js/lib/market-data.js`) и подписаны «Синтетические данные». Учебные сценарии строятся по заданным точкам разворота, поэтому программа знает правильный ответ (где уровни, где пробой). Графики в исторических кейсах — схематичные реконструкции формы движения с пометкой «не реальные котировки».

## Структура

```
academy/
  index.html             оболочка и порядок подключения скриптов
  css/                   base (токены, кнопки), layout (каркас), components
  js/core/               пространство имён, прогресс (localStorage), DOM-хелперы, роутер
  js/lib/                rng, индикаторы, риск, генератор данных, движок симулятора, тренер, бэктест — чистые функции
  js/chart/              canvas-график (свечи, объём, RSI/MACD, уровни, клики, зум) и SVG-иллюстрации
  js/course/             контент: m1–m7, словарь, кейсы, банк экзамена, индекс курса
  js/tasks/              интерактивные задания
  js/views/              экраны: главная, курс, урок, симулятор, экзамен, справочник, профиль, виджеты
  tests/                 node:test (логика и контент) + браузерный прогон Playwright
```

Как добавить урок: добавьте объект в массив `lessons` нужного модуля в `js/course/mN.js` (поля `title`, `minutes`, `goal`, `theory`, `analysis`, `mistakes`, `practice`, `quiz`, `summary`). Идентификаторы проставятся автоматически; тест `tests/content.test.js` проверит структуру.

## Тесты

```
cd academy
node --test tests/*.test.js                 # логика: индикаторы, риск, движок, бэктест, прогресс; валидация контента
node tests/browser/academy.browser.mjs      # все экраны на 1280 px и iPhone 13, прохождение урока, симулятор (нужен Playwright)
```
